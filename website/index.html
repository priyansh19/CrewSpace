Get started in 3 steps

  1. Install — npm install -g crewspace
  2. Run — crewspace start
  3. Open — browser opens automatically at localhost:3100

What's inside

  • Local AI adapters — Claude, Gemini, Cursor, Codex and more
  • 3D office workspace with role-based agent hierarchy
  • Task queues, budget policies, approval gates
  • Embedded database — your data never leaves your machine
